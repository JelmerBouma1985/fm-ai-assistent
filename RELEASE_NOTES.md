# Release Notes

## 2.1.0

### Features
- Support for FM 27.1.0. on game pass (very, very big thx to @canilbey to make this possible)
- Player traits and overall fitness (condition, sharpness, injury susceptibility, match load, training load, overall injury risk and fatigue) are available in the UI and AI agents.
- Tools option is available to enable/disable mcp tools
- When multiple managers are managing a club there is a dropdown in fixtures and ai context to select the manager you want to use
- In settings the jvm memory can be set
  - small  = 4gb
  - medium = 7gb
  - large = 10gb
  - very large = 13gb


### Bug fixes
- Maximum people in a game can now be 2 million instead of 500k
